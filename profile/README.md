## 🏛️ Core Ecosystem Repositories

- **[theta42/community](https://github.com/theta42/community)**: The community hub, engineering chronicle (50 PR announcements dating back to 2014), and free software showcase. Hosted at [community.theta42.com](https://community.theta42.com/).
- **[theta42/theta-suite](https://github.com/theta42/theta-suite)**: Unified one-command (`./setup.sh`) Docker Compose stack for self-hosted OIDC/LDAP identity, reverse proxy, secrets, and inventory mapping.
- **[theta42/proxy](https://github.com/theta42/proxy)**: High-performance OpenResty/Lua dynamic reverse proxy with native directory single sign-on and automated Let's Encrypt wildcard DNS challenges.
- **[theta42/theta-directory](https://github.com/theta42/theta-directory)**: Lightweight LDAP web GUI and REST directory engine with HP iLO discovery and live replication convergence.
- **[theta42/jump-host](https://github.com/theta42/jump-host)**: SSH jump host and bastion with automated WireGuard mesh service forwarding and dynamic UniFi/Proxmox/Docker inventory.
- **[theta42/theta-agent](https://github.com/theta42/theta-agent)**: Cross-platform Go daemon and system tray companion for zero-touch WireGuard mesh auto-roaming and directory enrollment.
- **[wmantly/turing-multi-gpu-llm-server](https://github.com/wmantly/turing-multi-gpu-llm-server)**: 32GB GDDR6 inference server on repurposed hardware (CMP 50HX mining silicon + RTX 2060 12GB) pulling ~33W at idle with 500 tok/s prefill speeds.
- **[wmantly/maki](https://github.com/wmantly/maki)**: Native Rust AI coding assistant extended with remote control tunneling and a dedicated management Web UI.
- **[simpleworkjs](https://github.com/simpleworkjs)**: Zero-DSL application stack for Node.js (`@simpleworkjs/conf`, `backend`, `orm-identity`, `bao-conf`).
- **[codeland-ecosystem](https://github.com/codeland-ecosystem)**: Self-hosted serverless runtimes in isolated Linux containers (LXC) across 24 programming languages.
